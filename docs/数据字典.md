# 数据字典与指标口径

## repo_metrics（项目指标表）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 项目名称 | VARCHAR | GitHub 仓库名 |
| 所属组织 | VARCHAR | 仓库所属组织/用户 |
| 主语言 | VARCHAR | GitHub 判定的主语言 |
| Star数 | INT | 星标数 |
| Fork数 | INT | 派生数 |
| 关注数 | INT | watchers（subscribers） |
| 开放Issue数 | INT | 未关闭 Issue + PR |
| 创建日期 | DATE | 仓库创建日期 |
| 创建年份 | INT | 创建年份，用于分组 |
| 最近推送日期 | DATE | 最近一次推送日期 |
| 仓库大小MB | DECIMAL | 仓库体积 |
| 许可证 | VARCHAR | SPDX 许可证标识 |

## weekly_commits（周提交表）
| 字段 | 说明 |
| --- | --- |
| 项目名称 | 关联 repo_metrics |
| 周起始日期 | 统计周的起始日（周一） |
| 年周 | ISO 年周编号，如 2026-W05 |
| 提交数 | 该周提交次数（GitHub stats/participation） |

## 指标口径
1. Star 总数、Fork 总数均为对应字段求和；
2. 收录项目数使用记录数（COUNT）统计；
3. 近一年提交总数为 weekly_commits.提交数 求和；
4. 主语言占比按 language_summary.Star总数 求和后计算百分比。
