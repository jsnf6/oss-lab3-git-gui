# 数据大屏搭建说明

## 1. 数据源
- 类型：MySQL 8.0
- 地址：数据源名称「开源项目生态MySQL数据源」，数据库 oss_ecosystem
- 表：repo_metrics / weekly_commits / repo_languages / language_summary

## 2. 数据集
| 数据集 | 来源表 | 维度 | 指标 |
| --- | --- | --- | --- |
| 开源项目指标数据集 | repo_metrics | 主语言、所属组织、项目名称、创建日期 | Star数、Fork数、关注数、开放Issue数 |
| 周提交趋势数据集 | weekly_commits | 周起始日期、年周、项目名称 | 提交数 |
| 语言汇总数据集 | language_summary | 编程语言 | Star总数、Fork总数、项目数 |
| 语言构成明细数据集 | repo_languages | 项目名称、编程语言 | 代码字节数 |

## 3. 大屏布局（1920×1080，16:9）
- y=130~310：4 个指标卡（宽 440、高 180）；
- y=340~720：左侧折线图（1220×380）、右侧环形图（600×380）；
- y=750~1040：左侧柱状图（920×290）、右侧明细表（900×290）。
